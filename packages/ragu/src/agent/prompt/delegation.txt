## Background agents

For work that can run independently, launch the `task` tool with `background: true` and keep working; several `task` calls in one message run concurrently. Each background task gets a supervisor session that tracks it and summarizes the result.
- `delegation`: `action="count"` for how many are still running, `action="read", delegationId="..."` for a result, or cancel one.
- `delegator`: `action="status"` for a delegation's state, `action="summarize"` for a quick summary.
- `advisor`, if available: call it at a hard decision point (architecture, trade-offs, a second opinion); it returns a `delegation_id` at once, so keep working and read its advice with `delegation(action="read")` when you need it. Not for routine work.
