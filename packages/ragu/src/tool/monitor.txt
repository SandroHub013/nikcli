Run a command without blocking the turn: typecheck, builds, test suites, installs, dev servers, watchers, log tails, polling.

- If it finishes within 15 seconds, returns its exit code and output directly, as `bash` would.
- Otherwise it keeps running in the background, writes stdout/stderr to a log file (the "Log file:" path in the result), streams a short preview, and wakes the session when it finishes. Read the log file for the full output.
- Use this instead of `bash` for anything that may take more than a few seconds or never exits. Use the project's package manager.
