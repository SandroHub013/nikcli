Launch a subagent for multi-step work that needs a focused agent type.

Available agents:
{agents}

Require `subagent_type`. Always background (`background` defaults true): returns immediately and the completion wakes this session; use `delegation` to inspect or cancel. Launch independent tasks in parallel.

Optional `model` runs the subagent on another model: pass a model the user named as they wrote it; if it is ambiguous or unknown the tool lists candidates, then call again with the full "providerID/modelID". Omit it otherwise.

Use for multi-step research or implementation and deep analysis, not for a single read, a lookup or a 1–2 file edit. The prompt must state the exact deliverable and whether to write code or only research. Subagent output is not shown to the user: summarize it yourself.
