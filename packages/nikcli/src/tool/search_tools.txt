Find and load tools that are not in your toolset yet.

Only the core tools are sent with their full schemas on every request. The others are deferred: they are listed at the end of this description by name and a one-line summary, and once loaded a deferred tool is a regular tool — full schema included — for the rest of the session.

The query is either:
- Exact tool names, comma-separated (e.g. "webfetch" or "webfetch,websearch"). Each deferred one is loaded, and its schema is available from your next step. Prefer this whenever the list below has what you need.
- A capability keyword (e.g. "image", "browser", "git") when you don't know which tool provides it. It is matched against the names and descriptions of every tool in the session, loaded or not, and the best few deferred matches are loaded.

Only tools this session can actually use are listed or loaded — anything disabled or denied by permission is left out.

Calling a deferred tool by name without loading it first also loads it, but you have not seen its parameters yet, so the call may be rejected; load it here first unless its arguments are obvious.

When NOT to use:
- The tool is already in your toolset: call it directly.
- For searching the codebase, use grep or glob instead.
