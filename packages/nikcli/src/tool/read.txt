Read the contents of a file or directory. Supports text files, images, and PDFs. Images and PDFs are presented directly to the model.

- Each text line is prefixed with its 1-based number as `<line>: <content>`; the prefix is not file content, never copy it into an edit. Directory entries come one per line, directories ending in `/`.
- `filePath` should be absolute. Returns up to 2000 lines; `offset` (1-based) and `limit` page through larger files and directories. Lines over 2000 characters are truncated. Prefer one larger read over many small slices.
- Read several files in parallel in one response when you know you need them.
- An empty file returns a system reminder instead of contents. Images and PDFs over 20 MiB are rejected.
- A missing path errors with `File not found: <path>` and may suggest up to three similar siblings.
