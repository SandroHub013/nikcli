# nikcli Homebrew Tap

Unofficial [Homebrew](https://brew.sh/) tap for [nikcli](https://github.com/nikcli/nikcli) — an AI-native CLI agent that researches, plans, and writes code.

## Installation

```bash
brew install nikomatt69/tap/nikcli
```
